# Такт — учебное время

Тема: «Разработка и исследование учебного приложения для управления временем студентов».
Автор: Очкина София Леонидовна (`sofiaochkina815-com`).

Личные задачи с приоритетами и дедлайнами, плановые и фактические минуты, дисциплины и категории, недельные планы, цели и учебные сессии. Аналитика, CSV и PDF-отчёт помогают сопоставлять план и результат. Куратор получает агрегаты только с согласия студента. Есть приватные PDF/TXT-материалы задач, публичное руководство, обратная связь и административный кабинет. Учёт ограничен 24 часами за сутки; завершённая сессия не записывает время повторно.

## Запуск

Python 3.12 или новее:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_local.py
```

Откройте http://127.0.0.1:8022 и зарегистрируйте личный аккаунт. Миграции применяются автоматически. В IDE выберите интерпретатор `.venv/bin/python` и нажмите Run в `run_local.py` без параметров. Остановка — Stop или Ctrl+C.

По умолчанию используется локальная SQLite; поддерживается локальный PostgreSQL через `DATABASE_URL`. Переменные из `.env` автоматически не читаются. Подробности и смена порта — [docs/LOCAL_RUN.md](docs/LOCAL_RUN.md).

```sh
.venv/bin/python run_local.py --check
.venv/bin/python main.py test
.venv/bin/python main.py createsuperuser
```

Последняя команда создаёт административный аккаунт с интерактивным вводом пароля. Для отдельного пустого аккаунта можно подготовить вымышленные данные: `python main.py seed_demo --user ИМЯ`. Команда не перезаписывает личные записи.

Прогресс и незавершённые проверки — [docs/PROGRESS.md](docs/PROGRESS.md).
