# Такт — учебное время

Учебный веб-сервис по теме «Разработка и исследование учебного приложения для управления временем студентов».
Автор: Очкина София Леонидовна (`sofiaochkina815-com`).

## Локальный запуск

Python 3.12 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py migrate
python main.py
```

Откройте http://127.0.0.1:8022 и зарегистрируйте собственный аккаунт.
Тесты: `python main.py test`. Проверка конфигурации: `python main.py check`.
Для локального старта используется SQLite. Для PostgreSQL задайте переменную окружения `DATABASE_URL`, затем выполните миграции. `.env.example` описывает переменные; автоматическая загрузка `.env` пока не реализована.

## Состояние разработки

Сейчас работают регистрация, вход, личные задачи (создание, изменение, завершение, удаление), приоритеты и дедлайны, плановые минуты и записи фактического времени с историей. Сумма записей за сутки ограничена 24 часами, будущие даты запрещены. Доступ проверяется по владельцу задачи.

Добавлены личные дисциплины и категории, поиск/фильтры/сортировка и страницы списка задач, недельный бюджет и сопоставление нагрузки с доступным временем. Недельный план группирует оценки задач по дедлайнам, фактическое время — по датам работы. Приложение использует собственные имена cookies, чтобы не сбрасывать вход в соседнем локальном проекте.

План и ещё не выполненные требования находятся в `docs/REQUIREMENTS.md` и `PLAN.md`.
Публикация на хостинге выполняется после готовности основных пользовательских сценариев.

Группы: `/groups/` — приглашение кодом и сводки для куратора с добровольным согласием. Цели: `/goals/` — фактические минуты за период/дисциплину и архив. Сессии: `/sessions/` — занятия без пересечений и однократная запись фактического времени при завершении. Это ручной учёт результата занятия, не секундомер.

Публичное руководство: `/guide/about/` и девять связанных разделов, меню доступно на каждой странице. Административный кабинет `/cabinet/` требует активного staff-аккаунта и содержит обзор, аккаунты, группы, справочники, проверку учёта и обращения. Для локального административного аккаунта используйте `main.py createsuperuser`.

Личные PDF/TXT материалы задачи выдаются только через проверенный маршрут скачивания; каталог `.local/private-files` не публикуется. PDF-отчёт находится в аналитике и по `/reports/study.pdf`; шрифты и их лицензия поставляются в planner/fonts.
