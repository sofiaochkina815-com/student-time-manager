# Воспроизведение локального комплекта

`.venv/bin/python scripts/verify_local_install.py` копирует отслеживаемые исходники в отдельный временный каталог и создаёт новый venv. Команда устанавливает requirements.txt, проверяет зависимости, применяет миграции к пустой SQLite и запускает все тесты. Для установки нужны доступные пакеты или кеш pip.

Затем создаётся вымышленный аккаунт/демонабор, проверяются восемь кабинетных страниц, включая исследовательское сравнение, и PDF. Настоящий сервер запускается из другого рабочего каталога; HTTP главной и CSS проверяются на loopback. Собственный процесс завершается, временный каталог удаляется. Отчёт содержит SHA исходников и версии зависимостей; личные базы и файлы в комплект не копируются.

23 ноября проверка пройдена. SQLite не доказывает конкуренцию PostgreSQL, визуальная браузерная приёмка остаётся открытой. Аналитика текущих задач и записей описательная; исторические изменения дедлайнов не восстанавливаются и причинный эффект приложения не заявляется.

## Настоящий браузер

Для отдельного QA-окружения: `python3 -m venv .qa-venv`, `.qa-venv/bin/python -m pip install -r requirements-qa.txt`, затем `.qa-venv/bin/python scripts/verify_browser.py --app-python .venv/bin/python`.

Временная копия получает пустую базу и вымышленный личный аккаунт. Исправлены пустые HTML-поля дат и выход таблицы сравнения за экран. Все шесть снимков reports/local-visual-v1 просмотрены. Таблица сравнения доступна с клавиатуры и прокручивается внутри своего блока. Это один браузер/демосценарий; полный аудит доступности и совместимости не заявляется. Личные файлы, аккаунты и исходная БД не копируются, свои сервер и браузер завершаются.
