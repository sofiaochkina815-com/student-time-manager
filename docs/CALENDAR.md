# Учебный календарь

/calendar/ объединяет собственные дедлайны задач, учебные сессии и агрегат фактического времени за каждый день месяца. На desktop показана неделя из семи колонок, на узких экранах — последовательные карточки. Завершённые задачи и отменённые занятия сохраняют статус. Дедлайны читаются из текущих задач: изменение даты не восстанавливает старый календарь. Сессия через полночь делится по локальным дням, факт учитывается отдельно.

Показываются первые1000 задач и1000 занятий с явным сообщением о неполном перечне. Суточные фактические минуты агрегируются по всем личным записям. Фильтруется только выбранный месяц1900–2100; нет передачи индивидуальных строк куратору.

Ссылка «Скачать месяц iCalendar» формирует приватный .ics по [RFC5545](https://www.rfc-editor.org/rfc/rfc5545.html): UTF-8, CRLF и переносы до75 октетов без разрыва символа. Дедлайн — прозрачное событие на весь день с исключающей конечной датой; занятия содержат UTC начало/конец и статус отмены. Названия экранируются, управляющие символы не добавляют свойства. UID стабилен в пределах текущего секрета приложения и не содержит имени/email. При превышении лимита экспорт отклоняется целиком.

Это ручной снимок, не подписка и не автоматическая синхронизация. Повторный импорт и обработка одинаковых UID зависят от календарного клиента. Файл содержит личные названия задач; храните его как собственные учебные данные. Фактические записи времени не экспортируются вторым набором событий.
