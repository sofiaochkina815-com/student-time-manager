# Обслуживание приватных DB-файлов

`python main.py cleanup_private_blobs` выполняет только проверку и возвращает счётчики. По умолчанию проверяются до1000 объектов старше7дней. Удаление требует явного `--delete`; минимальный возраст не может быть меньше суток. Например, `python main.py cleanup_private_blobs --older-than-days 14 --delete` удаляет только старые неиспользуемые байты поддерживаемого формата attachments/ID/UUID.pdf либо .txt.

Все имена, на которые ссылаются материалы задач, сохраняются независимо от выбранного backend. Перед удалением повторно проверяются ссылка и возраст под блокировками пользователя/объекта. Новые объекты и неизвестные имена не удаляются. Исходные файлы файлового backend команда не затрагивает. При большом объёме пакет можно повторить после проверки отчёта.

Команда предназначена для объектов, оставшихся после аварии между удалением записи материала и callback очистки. Она не исправляет повреждённые документы и не восстанавливает утраченные файлы.
