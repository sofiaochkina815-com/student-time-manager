# Демонстрационные данные

Создайте отдельный обычный аккаунт через регистрацию, затем выполните `.venv/bin/python main.py seed_demo --user ИМЯ`. Пароль в команду не передаётся. Команда заполняет только пустой аккаунт: 14 задач и записей времени, две дисциплины, категория, недельный бюджет и цель. Повторный запуск не добавляет копий. Существующий личный учёт не перезаписывается.

Данные вымышленные, даты отсчитываются от дня первого запуска. Они показывают сценарии интерфейса и не подтверждают результативность приложения в исследовании реальных студентов. Маркер DemoDataset — служебная таблица, не дополнительная предметная сущность для выполнения нормы.
