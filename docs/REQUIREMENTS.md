# Требования проекта

Автор: Очкина София Леонидовна. Направление: бизнес-информатика, цифровая экономика.
Источник: индивидуальное задание, раздел «Требования к разрабатываемому сетевому ресурсу», пункты 1–21. Приложения для 1С, мобильных приложений и ML относятся к другим типам проектов.

## Предметная задача

Студент планирует учебные задачи, учитывает фактическое время и сопоставляет план с результатом. Куратор видит согласованные данные учебной группы; администратор управляет доступом и справочниками. Роли и исследовательские метрики развиваются отдельными этапами.

## Обязательные результаты

- Python и Django; 50+ содержательных коммитов в период практики и подготовки ВКР.
- 2000+ логических строк кода, включая разметку, без пустых строк и комментариев.
- 10+ содержательных публичных страниц, 10+ пунктов меню, хлебные крошки на каждой странице.
- SQL-база с 10+ таблицами, миграции и демонстрационные данные в репозитории. Для итоговой версии — PostgreSQL по шкале оценивания веб-проектов.
- Три роли: студент, куратор, администратор; 5+ страниц личного кабинета и 5+ административных страниц.
- Обратная связь, работа с файлами, экспорт документов, адаптивность, ФИО автора в подвале.
- Собственная реализация, отсутствие пустых страниц.
- Анализ AS IS / TO BE, ТЗ, архитектура, модель данных, описание прав и тестирование в отчёте.

## Планируемые сущности

Учебная группа, профиль студента, дисциплина, учебная задача, категория задачи, запись времени, учебная сессия, цель, недельный план, обратная связь. Технические таблицы Django не заменяют проектирование предметных данных.

## Ближайший этап

Регистрация и вход; создание задачи с дедлайном, приоритетом и оценкой времени; изменение статуса и удаление с подтверждением; учёт фактического времени и сравнение с планом. Чужие данные недоступны другому пользователю.

Это первый этап. Реализацию всех обязательных пунктов сверяем перед сдачей.

Актуальная архитектура и проверяемая матрица: ARCHITECTURE.md, reports/requirements-audit-v1.json. Консервативный подсчёт1736 единицы пока ниже2000; таблицы/страницы/роли проверяются отдельно. Локальный браузерный цикл воспроизведён в ACCEPTANCE.md. Исследование на реальных студентах не выдаётся за выполненное.
